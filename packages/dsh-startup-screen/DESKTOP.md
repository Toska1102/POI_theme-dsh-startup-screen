# macOS 桌面接入

目标应用为 DeepSeek Harness Desktop。已检查的本机版本为 `0.2.1-rc.5`。

## 加载路径

桌面主页面地址为 `dsh-app://app/`。Electron 从应用包内读取前端首页；插件的原始 `tapIndex()` HTML 修改不进入该首页。DSH 通过 ModuleLoader 加载 `lib/client.js`，本插件在 `apply()` 中执行 `selfBoot()`。

客户端先读取 `/dsh-startup/config`，再加载样式与运行时。该自定义协议把 `/dsh-startup/*` 请求转发到已认证的本地 Host。资源服务支持 PNG、TTF 和 MP3，仅允许包内白名单文件名。

Web profile 使用 `tapIndex()` 提前注入启动层。两条路径共用配置、运行时与设置面板。自举发生在客户端插件加载后，不能保证覆盖桌面应用的最早首帧。

## 视口与 Retina

设计坐标为 2560×1440。实际布局使用 CSS 视口，镜头与目标框统一缩放。HUD 独立布局并保留最小字号和 44px 操作高度。

macOS 窗口使用 `hiddenInset` 标题栏。左上角摄像头信息距离顶部至少 58 CSS px，为系统窗口按钮保留空间。插件保持原生窗口按钮可用。

浏览器测试覆盖 2560×1440、1280×820、1470×956 与 800×650 视口，以及 1×/2×像素比例。浏览器测试不能替代实际 DSH 的冷启动、跨屏、标题栏和声音验收。

## 安装后检查

1. 在 DSH 设置中打开「POI 启动动画」。
2. 保存名称和编号，立即预览并核对显示值。
3. 在内置 Retina 屏播放，检查目标框、档案卡和按钮。
4. 移到外接屏，检查缩放与清晰度。
5. 检查两次确认、欢迎人声、跳过和连续重播。
6. 完全退出后重新打开，检查首次加载和播放频率。

应用存在运行中任务时，先完成独立预览与浏览器验证；安装和重启安排在可中断时段。
