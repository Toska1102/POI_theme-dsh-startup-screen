# 声音

## 人声

| 文件 | 阶段 | 内容 |
| --- | --- | --- |
| `line-1.mp3` | 03 | 访问许可 |
| `line-2.mp3` | 04 | 身份确认 |
| `line-3.mp3` | 05 | 接收访问需求 |
| `line-4.mp3` | 06 | 开始读取权限 |
| `line-5.mp3` | 07 | 读取完毕、核验通过 |
| `line-6.mp3` | 08 | 欢迎 |

六段录音沿用原插件。首轮播放预加载全部录音。首次点击或按键解锁 AudioContext；需要确认时，第一句人声在解锁后播放。人声保持原速。用户提前确认时，画面等待该句结束。

关闭确认的自动模式，在首次用户操作前保持静音。录音缺失或解码失败时，阶段继续按视觉时间推进。素材与声音设备异常受到阶段超时保护。

## 界面音效

阶段推进、确认和核验通过使用 Web Audio 合成的短音效。界面音效与人声分别设置音量。界面音效关闭后，人声仍可播放。

## 生命周期

每次播放独立管理 AudioContext 和全部活动声音节点。跳过、完成及重播销毁旧实例时，停止所有节点并关闭 AudioContext。播放节点结束后断开连接。人声不回退到系统 TTS。
